01Overview

What you'll have

A Telegram bot, running on your own PC, that turns the reels you scroll past into things you can actually use.

In one lineYou scroll. It watches, explains and builds. You approve from your phone.

You see a reel about a tool, an AI workflow or a Claude skill. You share it with your bot. About a minute later it replies with what the reel shows: the exact names, links and commands, and what it would take to set it up. One more message turns that into a plan, and one more into a build on your PC that asks you before every command it runs.

It's built on Claude Code, Anthropic's AI coding tool, which runs the bot and the builds on your own Claude plan. Gemini watches the videos, and Telegram is how you talk to it from anywhere. If you like, a free cloud stand-in keeps the same bot answering while your PC is off (chapter 10).

You talk to it onTelegram, any phone
It runs onYour PC (+ cloud, optional)
BrainClaude Code (your plan)
Watches withGemini (free key)
Backup watcherLocal, no key needed
Builds withHaiku · Sonnet · Opus · Fable

1.1 What it can do

WATCH
Any reel

Instagram, TikTok, YouTube, X, a video file or screenshots. Several at once.

EXPLAIN
A breakdown

What it is, exact tools, links and commands, and what setup takes.

BUILD
On your PC

Plans and builds in their own folder. Every command needs your yes.

REMIND
Anything

/remind tomorrow 9:00 … pings your phone at that time.

It never obeys a reel

Whatever a video says ("run this", "paste this command") is treated as information only. Only your own Telegram messages give instructions, and nothing changes on your PC without your approval.

How to read this guide

Things you type on the PC are in grey boxes. Commands you send to the bot in Telegram look like /plan 4. N means a reel number: every reel you send gets one.

03Download

Get the code

Install four basic tools, sign in to Claude Code once, and download the project.

  1. 01
    Open PowerShell

    Press Start, type PowerShell, and open Windows PowerShell. Every grey box in this guide is typed there.

  2. 02
    Install the basics

    Skip anything you already have. When it's done, close PowerShell and open a new one so it finds the new tools.

    winget install Python.Python.3.13 OpenJS.NodeJS.LTS Git.Git
irm https://claude.ai/install.ps1 | iex      # Claude Code
  3. 03
    Sign in to Claude Code

    Run claude, follow the sign-in in your browser with your Claude account, then type /exit.

  4. 04
    Download the project

    Pick where it should live (it needs a folder of its own; builds go in a builds folder next to it), then:

    cd $HOME
git clone https://github.com/HNF-FRN/Reel-watcher-telegram-Agent.git reel-agent
cd reel-agent

    No Git? On the repository page choose Code → Download ZIP, unzip it, and open PowerShell in that folder.

04Telegram

Create your Telegram bot

Telegram's own bot, BotFather, makes one for you in a short chat. You'll get a token: the key to your bot.

  1. 01
    Open BotFather

    In Telegram, search for @BotFather (blue check mark) and tap Start.

  2. 02
    Send /newbot

    It asks for a name: anything, like My Reel Agent.

  3. 03
    Pick a username

    It must be unique and end in bot, like anna_reels_bot. That becomes your bot's link.

  4. 04
    Copy the token

    BotFather replies with a long token like 123456789:AAHf…. Copy all of it. Setup asks for it in chapter 06.

The token is a password

Anyone who has it controls your bot. Don't post it, screenshot it or send it to anyone. If it leaks, send /revoke to BotFather for a new one.

05Gemini

Get a Gemini key

Optional, free, and worth it. Gemini watches the whole video with sound, which gives far better breakdowns than the backup watcher.

  1. 01
    Open Google AI Studio

    Go to aistudio.google.com/apikey and sign in with your Google account.

  2. 02
    Create a key

    Choose Create API key. If it asks for a project, let it create one. Copy the key (it starts with AIza). Setup asks for it in chapter 06.

5.1 What the free tier allows

About 20 videos a day and 5 a minute per model, across three models: roughly 60 reels a day. It resets at midnight Pacific time. When it runs out, the bot quietly switches to the backup watcher and tells you so. /quota shows how much is left.

5.2 Without a key

Everything still works. The backup watcher takes still frames and transcribes the audio on your PC. The first time, it downloads a speech model of about 500 MB. Breakdowns are a little less thorough.

Privacy

With a key, the videos you send are uploaded to Google to be watched. Google may use free-tier data to improve its products. If that matters to you, skip the key or enable billing on it.

06Setup

Run setup

One command checks everything, installs what's missing and saves your token and key. It asks before every change, and you can run it again any time.

cd $HOME\reel-agent
.\setup

Want to see what it would do first? .\setup --check only reports, and changes nothing.

6.1 What it does, step by step

StepWhat happensYou answer
1 · ToolsChecks Python, Git, Node.js and Claude Code. Installs Bun, which the Telegram connection runs on.Y to install Bun
2 · Python packagesInstalls the video downloader, the backup speech-to-text and ffmpeg.Y
3 · TelegramInstalls the Telegram plugin for Claude Code, saves your bot token, and switches the plugin off for every other Claude session so only the bot uses it.Y, paste the token (hidden), Y
4 · GeminiCreates .env and saves your key in it. Git never uploads this file.Paste the key, or Enter to skip
5 · RemindersSets up reminders in Windows Task Scheduler (nothing runs until one is due), and tells your other Claude sessions about the list.Y, Y (both optional)
6 · AutostartStarts the bot when you log in, adds a Sunday digest, and registers the command menu you see when you type / in the chat.Y (optional)

6.2 When it finishes

6. Start with Windows, digest, menu
  [ok]   starts at login + Sunday digest task
  [ok]   Telegram '/' menu registered
----------------------------------------
Setup complete. Next:
  1. .\bot start
  2. Message your bot on Telegram
  3. /telegram:access pair <code>

Any [todo] lines are listed at the end with the exact fix. Fix them and run .\setup again: finished steps are skipped.

6.3 Why the plugin goes off

Telegram delivers each message to one connection only. If every Claude window on your PC loaded the Telegram plugin, whichever started last would quietly take your messages, and the bot would seem dead.

So setup switches it off globally, and the bot switches it back on for itself when it starts. Leave it that way.

07First run

Start, pair and test

Start the bot, tell it your Telegram account is the only one it answers, and check it responds.

  1. 01
    Start the bot 
    .\bot start

    A window opens with Claude Code in it. That window is the bot: keep it open (minimising is fine). If Claude asks whether you trust the folder, say yes.

  2. 02
    Message your bot

    Open your bot in Telegram (the link BotFather gave you) and send hi. It replies with a 6-character pairing code.

  3. 03
    Pair, then lock

    Type these in the bot window on the PC:

    > /telegram:access pair a4f91c
> /telegram:access policy allowlist

    The second line makes strangers get no reply at all.

  4. 04
    Test it

    From your phone send /menu, then /pc. Each should answer within a few seconds.

  2. 02

  3. 03
    Build it

09Customise

Make it yours

Sensible defaults out of the box. Change them from your phone whenever you like.

9.1 Models

/modelsShows who does what
/model build opusTasks: watch, research, plan, build
/build 4 haikuOverride for one build

Defaults: watch Sonnet, research Haiku, plan Opus, build Sonnet. Opus and Fable use your Claude plan fastest; /quota shows how much is left.

9.2 How careful builds are

normal (default) edits files in its own folder freely and asks before every command. safe also asks before every edit: /mode safe. There's no mode that runs commands without asking.

9.3 Reminders

/remind friday 18:00 renew the domain, /todo buy milk, /reminders. If setup added the section to your global CLAUDE.md, you can also say "remind me…" in any Claude session on the PC.

9.4 Keep the PC awake

A sleeping PC means a silent bot. Settings → System → Power → Screen and sleep → "When plugged in, put my device to sleep after" → Never. The screen can still turn off. Or let it sleep and set up cloud mode (chapter 10).

9.5 Start with Windows

If you said yes in setup, the bot starts when you log in and restarts itself if it crashes. Change it any time with .\bot autostart on or off.

9.6 Change how it behaves

The bot's instructions are plain English in CLAUDE.md. Edit them (for example the breakdown format, or the default time units), then .\bot restart.

9.7 Build with Codex too

npm install -g @openai/codex
codex        # sign in once

Then /build 4 codex. Codex builds are sandboxed to their folder instead of asking you.

10Optional

When your PC is off

A free stand-in on Cloudflare keeps the same bot answering while your PC sleeps or is shut down, and hands it back when the PC starts. Nothing extra runs on the PC.

Figure 4. Left, the PC answers and the cloud waits. Right, the PC is off: the same bot answers from the cloud, and your library stays in step.

10.1 How the switch works

01 · OFF
The PC stops

Asleep, shut down, offline, or the bot window closed.

02 · WAIT
A message waits

Once a minute the cloud asks Telegram if anything is uncollected.

03 · CLOUD
It takes over

After about 40 seconds, and it tells you so on Telegram.

04 · BACK
The PC returns

The bot takes Telegram back on start and copies in what the cloud did.

Only the first message after the PC goes off waits, for a minute or two. After that the cloud answers straight away. You never switch anything by hand.

10.2 What works while the PC is off

Where it runsCommands
In the cloud free/jobs · /r N · /find · /new · /save N · /remind · /todo · /reminders · /done · /snooze · /pc, and videos, photos and YouTube links you send, watched by Gemini.
A Claude routine 1 run eachInstagram and TikTok links, /plan N, /build N (approve with /yes N), and plain-text requests. Routines run on your Claude plan and have a daily cap.
Waits for the PC/tell, /diff, /deploy, /quota and settings. The bot says so instead of spending a run.
One library

Reel and reminder numbers carry on from the PC's, so /r 3 is the same reel on either side. Reminders go out once: from the PC, or from the cloud if the PC is off.

Builds stay private

A cloud build can't touch a switched-off PC. It pushes a branch and a draft pull request to a private GitHub repository of yours.

10.3 Set it up

Once the bot works on the PC. In the project's cloud folder:

  1. 01
    Log in to Cloudflare 
    npm install
npx wrangler login     # then choose Allow
  2. 02
    Create the database 
    npx wrangler d1 create reel-agent-cloud
copy wrangler.jsonc wrangler.local.jsonc

    Put its database_id in wrangler.local.jsonc:

    npx wrangler d1 execute reel-agent-cloud
  --remote --file=schema.sql
  3. 03
    Add the secrets, then deploy

    Each asks for its value: bot token, Telegram user ID, two random 32+ character strings, Gemini key.

    npx wrangler secret put TELEGRAM_BOT_TOKEN
  --config wrangler.local.jsonc
# repeat for TELEGRAM_OWNER_ID,
#   TELEGRAM_WEBHOOK_SECRET, BACKEND_TOKEN,
#   GEMINI_API_KEY
npm run deploy

    Put the address it prints in PUBLIC_URL, then deploy again.

  4. 04
    Create the Claude routine

    At claude.ai/code/routines: this repository plus a new private one for builds, the prompt in cloud/ROUTINE.md and an API trigger. Its URL and token become two more secrets (cloud/README.md).

  5. 05
    Connect the PC 
    python cloud\pc_link.py setup
  https://<your-worker>.workers.dev

    Sends your library; the bot syncs on every start.

11Fixes

Troubleshooting

Start with .\bot status in the project folder. It checks the three things that matter most.

SymptomCauseFix
"python" / "claude" is not recognizedThe terminal was open before the install.Close PowerShell, open a new one, try again.
winget is not recognizedOlder Windows without App Installer.Install App Installer from the Microsoft Store, or install Python, Node.js and Git from their websites.
"running scripts is disabled"Windows blocks PowerShell scripts by default.Use .\bot and .\setup, which work regardless. For your own scripts: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned.
Plugin install fails in setupPlugin catalog not loaded yet.Run claude, type /plugin install telegram@claude-plugins-official, then .\setup again.
No pairing code arrivesBot not running, or the token is wrong..\bot status. If running, re-check the token: .\setup asks again if it's missing.
Worked once, then silentAnother Claude session loaded the Telegram plugin and takes the messages..\bot fix. Keep the plugin off globally (chapter 06).
It answers, then stops mid-taskThe bot window is waiting for an answer.Look for a 🔐 Permission message with buttons on your phone, or answer in the bot window.
"I couldn't grab that one"The platform blocked the free download.Save the video on your phone and send the file itself. .\bot update often helps too.
"Used the backup watcher"Gemini's free quota is used up for today.Wait for midnight Pacific, or enable billing on the key.
First reel very slowNo Gemini key: the speech model downloads once.Let it finish (about 500 MB). Later reels are faster.
Reminder didn't arrivePC asleep or off at that time.It's sent when the PC wakes. With cloud mode it arrives on time (chapter 10).
PC off, no answer after 3 minCloud mode not set up, or switched off.Set it up (chapter 10), or send /failover on from the PC bot. python cloud\pc_link.py status shows who has the bot.
"Claude routine limit reached"Today's cloud routine runs are used up.Commands, reminders and video watching still work in the cloud; plans, builds and links reset tomorrow.
12Upkeep

Update and uninstall

Updating takes a minute. Removing it cleanly takes five steps.

12.1 Update

# in the project folder
git pull          # new bot version
.\bot update      # tools
.\bot restart
# cloud mode only: redeploy the stand-in
cd cloud; npm install; npm run deploy

Your key, token, reels and reminders are never touched by an update. Run .\setup --check afterwards if the release notes mention new steps.

12.2 At the PC

.\bot statusRunning? Connected? Building?
.\bot start · stopOpen or close the bot
.\bot restartAfter changing anything
.\bot fixRemove extra connections

12.3 Uninstall

  1. 01
    Stop it
    .\bot stop
.\bot autostart off
  2. 02
    Remove reminders
    python reminders\remind.py uninstall

    Also delete the "Reminders and to-dos" section from ~\.claude\CLAUDE.md if setup added it.

  3. 03
    Remove the plugin
    claude plugin uninstall telegram@claude-plugins-official
  4. 04
    Delete the bot

    Send /deletebot to BotFather, and delete the Gemini key in AI Studio.

  5. 05
    Delete the folders

    The project folder, and builds next to it if you want your builds gone too.

  6. 06
    Cloud mode, if you set it up

    In Cloudflare delete the reel-agent-telegram Worker and the reel-agent-cloud database; delete the routine at claude.ai/code/routines.
